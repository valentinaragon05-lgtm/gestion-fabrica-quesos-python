# gestion-fabrica-quesos-python
Programa de consola en Python que simula el sistema de ventas de una fábrica de quesos. Permite registrar ventas de distintos productos, aplicar descuentos según la forma de pago y ver informes con la facturación del día.

Es un proyecto de práctica que hice para aplicar lo que aprendí en el curso de Python. Lo desarrollé en Google Colab.
